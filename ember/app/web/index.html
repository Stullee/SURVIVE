                            Stop the agent with the kill switch?
                            
      
                            
        
                            The kill switch stops the agent for good: no more model calls, and a running cycle ends at its next call. It takes back every unlock too. Unlike Pause, Resume doesn't undo it.
                            
        
                            To let it run again later, you change "Kill switch reset" in the app's configuration and restart the app.
