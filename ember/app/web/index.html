                      Diagnostics
                      
        
                      A text report of the whole system, for troubleshooting. It never contains your API key or passwords, and it leaves out other people's text (the emails the agent read and wrote, the web pages it researched) and masks email addresses, one-time codes, tokens in links and the words you removed from your messages. Read it before you share it, and don't paste it into an AI tool that can change Ember's code: parts of it were written by the agent, which reads emails and web pages.

                      Stop the agent with the kill switch?
                      
      
                      
        
                      The kill switch stops the agent for good: no more model calls, and a running cycle ends at its next call. Unlike Pause, Resume doesn't undo it.
                      
        
                      To let it run again later, you change "Kill switch reset" in the app's configuration and restart the app.
