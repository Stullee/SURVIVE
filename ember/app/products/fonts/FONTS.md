# Fonts used for Ember's products

Unmodified copies from Google Fonts (https://github.com/google/fonts, branch `main`, fetched 2026-09-28),
each under the SIL Open Font License 1.1 (the `OFL-*.txt` files next to them). Fonts are embedded (subset) in the
PDFs Ember makes, as the licence allows; Word files only name the font.

| Family  | Files                          | Used as                                   | Word files name   |
|---------|--------------------------------|-------------------------------------------|-------------------|
| Carlito | `ofl/carlito/Carlito-*.ttf`    | `sans`: metric-compatible with Calibri    | Calibri           |
| Caladea | `ofl/caladea/Caladea-*.ttf`    | `serif`: metric-compatible with Cambria   | Cambria           |
| Poppins | `ofl/poppins/Poppins-*.ttf`    | `display`: headings                       | Poppins           |

Calibri and Cambria come with Microsoft Office, so a Word file set in them looks the same as its PDF on a
buyer's computer; Poppins is a free Google Font a buyer may have to install.
